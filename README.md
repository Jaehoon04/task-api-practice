# Task API

Spring Boot 백엔드 개발을 학습하기 위해 만든 Task 관리 REST API 프로젝트

Task의 생성, 조회, 수정, 삭제 기능을 구현하면서
Controller, Service, Repository 구조와 JPA, Validation, 예외 처리,
트랜잭션, 테스트 코드 작성 등을 학습하고 있음.

MySQL을 데이터베이스로 사용
Docker와 Docker Compose를 이용해 Spring Boot 애플리케이션과 MySQL 실행 환경을 구성

## 주요 기술

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Docker / Docker Compose
- JUnit / Mockito
